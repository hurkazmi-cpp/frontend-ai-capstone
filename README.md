# Frontend AI Engineer Capstone

This repository contains my capstone project for the Frontend AI Engineer internship track.

## Goals

- Build a modern frontend application
- Integrate AI-powered functionality
- Practice AI-assisted development
- Maintain clean Git history and documentation

## Tech Stack

- JavaScript / TypeScript
- React
- Next.js
- Tailwind CSS
- Node.js
- Git and GitHub
- AI APIs

## Routes

- `/` — Home
- `/upload` — Upload notes/PDF
- `/history` — Past uploads & quiz scores
- `/settings` — Preferences
- `/summary/[id]` — AI-generated summary
- `/flashcards/[id]` — AI-generated flashcards
- `/quiz/[id]` — AI-generated quiz
- `/health` — Health check page (confirms live data fetch)
